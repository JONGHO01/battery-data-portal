# 현재 포탈 안내

> 2026-10-22 최신 로컬 개발본 **v0.3.20 Unreleased** 기준입니다. GitHub `main`의 실행 코드는 아직 v0.3.13이며, 이 문서가 최신 실험 관리 소스의 배포를 뜻하지 않습니다. 설치 범위는 [README](../README.md), 실행 차이는 [실행 안내](RUNNING.md)를 확인하세요.

## 1. 프로젝트와 실험 배치

연구자를 선택하고 그 사람이 참여하는 프로젝트·실험을 봅니다. 프로젝트는 생성할 수 있으며, 삭제는 생성 근거·권한을 확인한 **빈 프로젝트**만 대상으로 합니다. 실험 자료를 연쇄 삭제하거나 자동으로 다른 곳에 옮기지 않습니다.

목록은 한 페이지 15개이며 페이지 이동은 한 곳에 표시합니다. 검색은 기준일·공정일·측정일·업로드일을 구분합니다. 날짜가 없다고 파일명이나 업로드일을 제조일로 대신 기록하지 않습니다.

새 배치 이름은 **날짜 → 소재 → 조성비 → 배치량 → 선택 공정** 순서로 자동 생성합니다. 알 수 없는 값이나 불필요한 끝 번호는 추가하지 않습니다. 기존 모든 실험 이름을 일괄 변경하는 작업은 별도 검토 대상입니다.

현재 새 이름의 상세 형식은 `날짜 소재-바인더-도전재_활물질비-바인더비-도전재비 니딩시간, 배치량 선택공정`입니다. 니딩 rpm·추가 공정은 입력했을 때만 붙습니다. **조성비 입력·배합량 계산은 활물질:도전재:바인더 순서**를 유지하므로 이름에 표시되는 성분 순서와 구별하세요. 이름은 공정이 실제 수행되었다는 증거가 아닙니다.

다른 프로젝트로 옮길 때는:

1. `선택`을 눌러 선택 모드를 엽니다.
2. 옮길 실험과 대상 프로젝트를 고릅니다.
3. 이동 내용을 확인하고 실행합니다.

체크나 대상 선택만으로 이동하지 않습니다. ID·참여 연구자·원본·공정·사진 연결을 유지하며 소유권을 넘기는 기능이 아닙니다. 권한이나 최신 기록 검증에 실패하면 부분 이동하지 않습니다.

## 2. 공정 조건

원본 메모에만 있던 핵심 조건을 공정 입력 항목으로 구분합니다. 알려진 값만 적고 단위를 함께 확인합니다.

| 공정 | 직접 기록하는 핵심 조건 |
|---|---|
| 1차 믹싱 | 활물질(A) + 도전재(B), rpm, 1회 작동 분·홀딩 분, 사이클 |
| 2차 믹싱 | 활물질(A) + 도전재(B) + 바인더(C), rpm, 1회 작동 분·홀딩 분, 사이클 |
| 니딩 | rpm, 정방향 분, 역방향 분, 사이클, 설정온도 |
| Pulverization | rpm, 수행 시간과 단위 |
| 체질 | 확인된 체 크기와 단위; µm와 mesh 구분 |
| 롤밀 | 단일 회전속도 rpm, 온도, 1차·2차 간격 |
| 롤프레싱 | 하중·장비 표기 단위, 진행 속도·단위, 온도 조건 |

A/B/C는 **역할**입니다. 실제 소재명은 각 실험의 확인된 조성을 사용하며 모든 바인더를 같은 물질로 치환하지 않습니다.

`(작동 2분 + 홀딩 3분) × 6사이클`은 한 믹싱 단계의 경과시간 30분입니다. 별도 수행한 니딩 후 30초 처리를 그 단계에 합치지 않습니다. 니딩도 양방향 시간과 반복 수가 모두 확인되어야 합계 시간을 계산합니다.

미확인 사이클·간격·날짜는 비워 둡니다. 과거 롤별 속도 기록에서 새 단일 rpm을 추정하지 않습니다. 변경 전 원문·버전·이력을 남기며 사진과 시료 연결을 임의로 바꾸지 않습니다.

## 3. 사진·SEM·토크

공정 사진은 실험·공정·파일 버전으로 연결합니다. 단계가 구분되지 않는 사진은 근거 또는 사용자 확인 없이 1차·2차로 나누지 않습니다.

SEM은 **시료 상태 → 측정 → 사진 버전**으로 확인합니다. 8개 단위 갤러리를 데스크톱 4열, 좁은 화면 2열·1열로 배치하고 개별 확대·전체 비교를 제공합니다. 카드 수는 독립적인 실제 제조 시료 수와 같지 않을 수 있습니다. 참고 이미지·동일 조건 자료·실제 측정 대상을 구분하세요.

토크는 시간과 실제 관측 열을 읽어 봅니다. 중복 구간을 독립 실험으로 세거나 관측 중 변하는 속도만 보고 설정 rpm을 확정하지 않습니다.

파일 등록과 물리적 실험 이력 확정은 다릅니다. 관련 자료가 존재해도 확인되지 않은 공정 수행이나 시료 생성 기록을 만들지 않습니다.

## 4. CYC·CV·EIS·전극 계산

- **CYC:** 성능·충전·방전 곡선과 유효한 원시 전압–용량 데이터가 있을 때 dQ/dV를 확인합니다. 최신 로컬본은 첨부 비교 갤러리와 지원되는 압축 WRD 읽기를 포함합니다.
- **CV:** 열·단위·검토 결과를 확인하고 전압–전류 그래프를 만듭니다.
- **EIS:** Nyquist·Bode·DRT와 재구성 오차·측정 대역·독립 KK 수치 진단을 구분합니다. 수치적 일치가 물리 모델의 타당성 증명은 아닙니다.
- **전극 계산:** 확인된 질량·조성·면적·두께·용량 기준을 사용합니다. 총질량과 활물질 질량, mg와 mg/cm²를 혼동하지 않습니다.
- **Fig:** 범위·색·문구를 조절하고 저장하며 지원되는 내보내기로 전달합니다. 모든 분석을 자동 보고서로 만드는 기능은 아닙니다.

파일 비교는 자동 병합·정규화·셀 동일성 확정을 뜻하지 않습니다. `_rs` 같은 접미사만으로 새로운 셀이라고 세지 않습니다. 읽지 못한 데이터는 이유를 표시하며 미확인 값을 0으로 만들지 않습니다.

## 5. 도우미: 로컬 조회와 외부 질문

| 구분 | 자료 처리 |
|---|---|
| 실험 목록·사진 요청 | 기존 API와 선택한 사람의 권한으로 로컬 조회 |
| 기간 요청 | 실험 기준일의 연·월·일; 연도 미지정 시 한국 날짜 기준 올해임을 표시 |
| 일반 AI 질문 | 설정된 연결과 매 전송 동의 필요 |
| 현재 실험 질문 | 제한된 텍스트 문맥을 미리 확인; 원본·사진 전체 자동 첨부 없음 |

`연구자 A의 2026년 9월 실험 보여줘`, `이 실험 사진 보여줘`처럼 요청합니다. 로컬 조회 결과와 사진은 외부 AI 대화 이력에 넣지 않습니다. 모든 자료를 한 번에 모델로 읽히거나 수정·삭제를 맡기는 기능이 아닙니다.

같은 담당자의 SPA 페이지 이동 시 대화·초안·진행 중 응답을 유지합니다. 답변 중 다음 질문을 작성할 수 있지만 자동 예약·전송하지 않습니다. 새로고침·담당자 변경 시 초기화하며 포탈 DB나 브라우저 영구 저장소에 대화를 저장하지 않습니다.

기존 데이터 관리의 **로컬 파일 검색**과 전역 **Codex 도우미**는 다른 기능입니다. 연결이 꺼져 있어도 연구자료를 외부 API에 보내 자동 대체하지 않습니다.

## 6. 조회 권한의 의미

계정 로그인과 공유 PC의 이름 선택은 다릅니다. 이름 선택은 신원 인증이나 사람 사이의 비밀 보장을 제공하지 않습니다.

전체 조회자는 서버에 명시한 기존 연구자 ID로 지정합니다. 표시 이름 변경으로 권한을 만들지 않습니다. 필터를 바꾸어 타인의 프로젝트·실험·허용 사진을 볼 수 있지만 수정·삭제나 관리자 원시 데이터 권한은 아닙니다.

이름 선택 모드는 loopback·로컬 SQLite·로컬 저장소에 한정합니다. 외부 서비스에는 별도 계정 인증과 영속 저장소가 필요합니다.

이 문서는 실제 로컬 구현의 안내이지 현재 GitHub 코드의 설치 완료 증명이 아닙니다. 최신 소스는 회귀 검증·선별 업로드 후 별도로 반영해야 합니다.
